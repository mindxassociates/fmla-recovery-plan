# FMLA Mental Health Recovery Plan

A bilingual, mobile-responsive static client resource focused on recovery during mental-health-related FMLA leave. Includes an English page and a Simplified/Traditional Chinese page, dark mode, interactive checklists and self-reflection tools, print/PDF support, return-to-work planning, and authoritative resource links.

## Files
- `index.html` — English
- `zh/index.html` — Chinese with Simplified/Traditional toggle

No build process or dependencies are required. Upload the repository directly to GitHub Pages, Cloudflare Pages, Netlify, or any static host.
